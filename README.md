## Описание

Задача N тел — классическая модель гравитационной динамики. В системе из более чем двух взаимодействующих тел возникает хаотическое поведение, при котором малые изменения начальных условий приводят к непредсказуемому расхождению траекторий.

Модель позволяет исследовать:
* Влияние **флуктуаций** начальных параметров (плотности и скоростей) на формирование структур.
* Роль начального **углового момента** в устойчивости системы.
* Влияние типа начального **пространственного распределения** (сфера, куб).

### Математическая модель

Уравнения движения для каждой *i*-й частицы:

$$
\frac{d\mathbf{r}_i}{dt} = \mathbf{v}_i, \quad m_i \frac{d\mathbf{v}_i}{dt} = \mathbf{F}_i
$$

Сила гравитационного притяжения с введением параметра смягчения (softening) \(\varepsilon\) для подавления сингулярностей при близких сближениях:

$$
\mathbf{F}_i = G \sum_{j \neq i} \frac{m_i m_j (\mathbf{r}_j - \mathbf{r}_i)}{(|\mathbf{r}_j - \mathbf{r}_i|^2 + \varepsilon^2)^{3/2}}
$$

## Численные методы

### 1. Алгоритм Barnes-Hut

Прямое вычисление сил имеет сложность \(O(N^2)\), что делает симуляцию больших систем невозможной. В работе используется древовидное разбиение пространства:
* Если группа частиц находится далеко от текущей (\(s/d < \theta\)), она заменяется одной фиктивной частицей в центре масс.
* Если близко — ячейка дробится дальше.
* Сложность алгоритма снижается до \(O(N \log N)\).

Для ускорения вычислений обход дерева и расчет ускорений скомпилированы через **Numba** (`@njit`).

### 2. Интегратор Leapfrog

Для численного интегрирования уравнений движения используется симплектический интегратор Leapfrog:

$$
\mathbf{v}_i^{n+1/2} = \mathbf{v}_i^{n} + \frac{\Delta t}{2} \mathbf{a}_i^{n}
$$

$$
\mathbf{r}_i^{n+1} = \mathbf{r}_i^{n} + \Delta t \mathbf{v}_i^{n+1/2}
$$

$$
\mathbf{v}_i^{n+1} = \mathbf{v}_i^{n+1/2} + \frac{\Delta t}{2} \mathbf{a}_i^{n+1}
$$

## Результаты экспериментов

* **Одиночное ядро:** При отсутствии достаточного начального углового момента и слабых флуктуациях система неизбежно коллапсирует в единое плотное центральное тело. Частицы на периферии, приобретая кинетическую энергию больше потенциальной энергии связи, навсегда покидают систему.
* **Хаотичность:** Минимальное изменение начальных скоростей (< 1%) кардинально меняет форму итоговой структуры, что подтверждает хаотическую природу задачи N тел.
* **Роль вращения:** При значительной угловой скорости центробежная сила балансирует притяжение. Облако фрагментирует на несколько локальных сгущений, которые впоследствии могут слиться в единое тело.

## Установка

Требуется Python 3.10+.

```bash
git clone https://github.com/alyona32003/Nbody-lab-2.git
cd Nbody-lab-2

# Установка зависимостей
pip install -r requirements.txt
pip install -e .
```

### Запуск через CLI

Быстрая проверка работы модели:

```bash
py -m nbody.cli --n-particles 500 --steps 10 --omega 1.01 --seed 42
```

### Симуляция и сохранение GIF

Запускает полную симуляцию (по умолчанию 2000 частиц, 500 кадров) и сохраняет результат в `results/nbody_collapse.gif`:

```bash
py scripts/run_simulation.py
```
